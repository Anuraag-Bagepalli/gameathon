# Gameathon 8.0

Public website, registration API, and admin dashboard for Gameathon 8.0 — a global game-building contest at Jyothy Institute of Technology, Bengaluru.

## Projects

- `gameathon/` — React + Vite public website
- `gameathon/backend/` — Express registration and contact API
- `gameathon-admin/` — Express admin dashboard and management API
- `render.yaml` — Render Blueprint for the API and admin services

## Local development

Copy the included `.env.example` files to `.env`, provide your own MongoDB connection string, then run each project's documented npm script.

Secrets must never be committed.
